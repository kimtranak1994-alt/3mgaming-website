👑 BỘ FILE MOD RIÊNG: HẮC BĂNG LÔI ĐIỆN (TRICERATOPS - CHUẨN 100% ẢNH MẪU)
================================================================================

Bộ Mod được thiết kế tỉ mỉ theo đúng ảnh mẫu "Hắc Băng Lôi Điện - Phiên bản giới hạn":
- Nền da: Đen huyền vảy bóng (Obsidian Jet Black #06080E)
- Vân hoa văn: Các tia sét và ngọn lửa Lam Lôi (Electric Cyan #00E5FF - #00FFFF)
- Lõi tia sáng: Bạch Băng (Ice White #FFFFFF) sắc nét nổi bật
- Mào & Gai sống lưng: Viền mào phát sáng xanh ngọc và các gai lưng bạch băng chạy dọc cột sống

--------------------------------------------------------------------------------
CÁCH 1: NẠP PRESET VÀO GAME CLIENT (ĐƠN GIẢN & NHANH NHẤT)
--------------------------------------------------------------------------------
1. Chạy file `1_Cai_Dat_Vao_Game_Client.bat`.
2. File sẽ tự động nạp preset màu vào game The Isle và copy sẵn Skin Code:
   `Triceratops10006080EFF06080EFF06080EFF00E5FFFF00F2FFFF00FFFFFF`
3. Vào game -> Chọn Triceratops -> Nhấn `Ctrl + V` để dán mã màu!

--------------------------------------------------------------------------------
CÁCH 2: DÙNG FILE TEXTURE 3D MOD (diffuse_hac_bang_triceratops.png)
--------------------------------------------------------------------------------
- Thư mục chứa file `diffuse_hac_bang_triceratops.png` (và `T_Triceratops_Adult_D.png`).
- File này đã được vẽ (bake) 100% từng đường tia sét, ngọn lửa, viền mào và gai lưng
  chuẩn khớp tuyệt đối với UV 3D của Triceratops.
- Dùng để đóng gói vào file `.pak` Unreal Engine hoặc dùng các tool mod texture client.
